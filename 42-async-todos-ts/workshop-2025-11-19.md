# Workshop 2025-11-19

Skapa en ny Vite-app med vanilla-ts template. Installera bootstrap med npm (eller länka till det med en `<link>` i `<head>`).

Kopiera över HTML, DOM-referenser och `renderTodos` från `41-typescript-todos`.

## 1. Hämta todos från API

Skapa funktionen `getTodos()` för att hämta todos från API:et (`GET http://localhost:3001/todos`). Spara ner i en array och rendera todos. Kalla på funktionen när sidan laddar in för första gången.

## 2. Lägg till todo i API

Skapa funktionen `createTodo(todo)` för att spara en todo i API:et (`POST http://localhost:3001/todos`). Ta submit-handlern från `41-typescript-todos` och anropa funktionen där istället för att lägga till den i `todos`-array:en.

## 3. 🌖 Toggla todo i API

Skapa funktionen `toggleTodo(id)` för att toggla en todo i API:et (`PATCH http://localhost:3001/todos/<id>`). Anropa funktionen när man klickar på en todo's titel.

## 4. 🚀 Radera todo i API

Skapa funktionen `deleteTodo(id)` för att radera en todo i API:et (`DELETE http://localhost:3001/todos/<id>`). Anropa funktionen när man klickar på en todo's knapp.
